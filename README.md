## Sobre mí

- Científico de datos con cinco años en el sector financiero, en riesgo de crédito: modelos de machine learning para originación, *behaviour* y cobranza, análisis de cartera y reportes para comités y auditoría.
- Lo que más me interesa es la automatización: convertir procesos y reportes manuales en pipelines, APIs y tableros que corren solos, y llevarlos hasta producción.
- Trabajo principalmente con **Python**, **R** y **SQL**; PostgreSQL y MySQL, Power BI, FastAPI, Streamlit, XGBoost y scikit-learn, Docker, AWS y Git.
